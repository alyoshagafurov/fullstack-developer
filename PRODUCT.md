## Platform

web

## Users

Primary: владельцы и руководители малого и среднего бизнеса в Таджикистане и
русскоязычном СНГ, которым нужен сайт, веб-приложение, бот или мобильное
приложение. Приходят из соцсетей, по рекомендации и из поиска; чаще с
телефона. Задача за один визит: понять, кто этот разработчик, что он умеет и
стоит ли ему писать — и оставить заявку через бриф. [inferred from the lead
flow in CLAUDE.md and the brief form; audience mix not confirmed]

Secondary: сам владелец (Алишер Гафуров) — обрабатывает заявки и публикует
кейсы через `/admin`.

## Product Purpose

Персональный сайт-портфолио full-stack разработчика (бренд aly, домен
aly.lat). Существует, чтобы превращать посетителей в квалифицированные заявки:
посетитель → Project Brief → база → админка → уведомление в Telegram. Успех —
заполненный бриф от подходящего клиента.

## Positioning

Один разработчик, который делает продукт целиком — дизайн, код, запуск,
поддержка — без цепочки подрядчиков, которых клиенту нужно сводить между
собой. Авторский тезис владельца: «Я создаю сайты, которые продают».
Четырнадцать услуг от лендинга до Telegram Mini Apps и нативных приложений.
Агентство не может честно обещать одну ответственность; шаблонный фрилансер —
полный цикл.

## Operating Context

- Язык: русский основной; таджикский и английский для хрома сайта. Описания
  четырнадцати услуг — только по-русски: владелец не хочет машинного перевода
  своих коммерческих текстов.
- Заявки: `/start-project` → Prisma / PostgreSQL (Neon) → админка (Next.js UI,
  авторизация и роли через Django) → Telegram. Telegram — ассистент, не CRM;
  заявки в нём не хранятся.
- Кейсы публикует владелец из админки; скриншоты — Vercel Blob (store ещё не
  создан; до этого загрузка честно отвечает «не подключено»).
- Хостинг: Vercel (сайт), Railway (Django), Neon (Postgres).

## Capabilities and Constraints

- Стек: Next.js 15 App Router, React 19, TypeScript (`strict: false` —
  историческое), Tailwind CSS 3.4 (не v4 — апгрейд не входит в визуальную
  работу), Prisma 6.19, Django 6.1 для админ-API.
- Маршруты: `/`, `/work`, `/work/[slug]`, `/services`, `/services/[slug]`,
  `/start-project`, `/admin/*`.
- Шрифты только self-hosted (`public/fonts`, woff2, latin + cyrillic); не
  больше двух семейств и четырёх файлов.
- Изображения через `next/image`. Фотографии владельца — как сняты: без
  фильтров, обесцвечивания и перекраски (требование владельца).
- Никаких стоковых фотографий и фотографий посторонних людей.
- Бюджеты из регламента Mimi v4.0 §6.3: LCP ≤ 2.5 с, INP ≤ 200 мс, CLS ≤ 0.1,
  Lighthouse mobile ≥ 90, JS первого экрана ≤ 150 KB gzip, анимации только
  transform/opacity ≤ 300 мс, `prefers-reduced-motion` уважается.
- Состояние зависимостей на момент записи: `lenis` и `gsap` используются в
  одном файле (`components/SmoothScroll.tsx`); `framer-motion` установлен и не
  используется нигде.
- Undecided: апгрейд Tailwind до v4; скиллы Emil Kowalski не установлены —
  по Mimi §2.2 их заменяют ближайшие по назначению (ECC motion, Impeccable).

## Brand Commitments

- Марка «aly» (строчные). `public/aly-logo.png` — логотип владельца; никогда не
  перерисовывать как текст и не заменять.
- Голос: от первого лица, на «вы», без агентского «мы». Авторские тексты
  владельца, менять только с его слов: заголовок героя, надбровник, подпись,
  описания четырнадцати услуг.
- Обязательные визуальные ограничения, названные владельцем в этой сессии и
  записанные без расширения: единственный цвет — медный акцент `#C0996F`,
  тёплый белый текст, графитовый фон; в остальном монохром.
- Одобренное владельцем направление перезапуска: «инженерный editorial» —
  движение только там, где объясняет изменение состояния; ни одного клише из
  списка Mimi §5.3 (бессмысленные градиенты, glassmorphism, ряды одинаковых
  карточек с иконками, гигантские заголовки везде, блобы, parallax,
  «въезжающие» секции, одинаковые радиусы на всём).

## Product Principles

1. Заявка — единственная конверсия; каждый экран либо ведёт к ней, либо
   объясняет, почему стоит.
2. Реальный контент владельца или честное отсутствие. Ничего не выдумывать.
3. Один разработчик — один голос: первое лицо, без агентской риторики.
4. Русский первый; остальные языки не ломают композицию.
5. Быстро на телефоне — оттуда приходит большинство.

## Accessibility & Inclusion

Установленный в проекте минимум: контраст AA (≥ 4.5:1 для текста), тач-цели
≥ 44 px, видимый `focus-visible`, `prefers-reduced-motion` отключает
декоративное движение. Проверка на трёх вьюпортах: 1440 / 768 / 390.
