# aly.lat

Портфолио Алишера Гафурова: публичный сайт, приём заявок и CRM-админка
в одном приложении.

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4,
Prisma 7 через драйвер-адаптер Neon, PostgreSQL на Neon, деплой на Vercel.

Django больше не используется: админка живёт внутри Next.js.

## Запуск

```bash
npm install
npm run dev
```

## Переменные окружения

| Переменная | Зачем | Где нужна |
|---|---|---|
| `DATABASE_URL` | база Neon | локально и на Vercel |
| `ADMIN_SESSION_SECRET` | подпись cookie админки, от 32 символов | локально и на Vercel |
| `TELEGRAM_BOT_TOKEN` | бот, четвёртый этап | позже |

Без `DATABASE_URL` сайт собирается и открывается: разделы, зависящие от базы,
рендерятся пустыми, а не роняют страницу.

## Что где лежит

| Путь | Что это |
|---|---|
| `app/` | маршруты. `app/admin/(workspace)` — всё за сессией |
| `components/sections/` | полосы главной страницы |
| `components/vitrine/` | витрина работ, подпись сайта |
| `lib/content/` | **все тексты сайта**, дословно из ответов владельца |
| `lib/admin/` | запросы админки |
| `prisma/schema.prisma` | схема; таблицы с префиксом `aly_` |
| `docs/rebuild/` | материалы пересборки: направление, промпты, анкета |

## Правила, которые легко нарушить

**Не запускайте `prisma db push` на этой базе.** Она общая со старой версией
сайта. Схема описывает только таблицы `aly_*`, поэтому Prisma считает все
остальные лишними и предложит их удалить — вместе с таблицами Django.
Изменения схемы применяются вручную, только операциями создания.

**Тексты правятся в `lib/content/`, а не в разметке.** Они принадлежат
владельцу и записаны дословно; вторая копия в компоненте разойдётся с первой.

**Кейсы и отзывы добавляются через админку.** Ничего не выдумывается: пустой
раздел честнее заполненного придуманным.
