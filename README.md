# Alisher Gafurov — Portfolio

Hyper-cinematic portfolio for Alisher Gafurov (Alyosha) — web developer × MMA fighter.

## Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger (cinematic scroll)
- Framer Motion (micro-animations)
- lucide-react (icons)

## Local dev
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Build
```bash
npm run build
npm run start
```

## Sections
1. **Hero** — fullscreen face/helmet 3D card flip on hover with parallax.
2. **Storytelling Scroll** — GSAP-powered camera transitions: studio → TV portal → octagon → return.
3. **About** — dual columns (Dev × Fight) with tech stack and discipline list.
4. **Projects** — alternating layout cards with hover scale + scanline overlays.
5. **MMA** — record band + photo gallery + fight log.
6. **Contact** — neon CTA, channel grid, big-name footer.

## Deploy
Push to GitHub and import to Vercel. Zero config needed.
