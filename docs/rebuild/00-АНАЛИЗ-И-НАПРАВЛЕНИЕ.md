## 1. Что говорят три референса

Разобрал их по слоям, а не «по настроению».

| Слой | «the act» | AirPods Max (лендинг) | AirPods Max (герой) |
|---|---|---|---|
| Земля | чистый белый | светло-серый, чередуется с белым | почти белый |
| Тип | огромный контрастный антиква-логотип | жирный гротеск поверх фото | — |
| Слово-призрак | нет | белое слово ЗА продуктом | серое слово во всю ширину ЗА продуктом |
| Объект | банка на белом, реальная тень | наушники парят, мягкая тень | наушники по центру, мягкая тень |
| Управление | маленькие пилюли | тонкая круглая стрелка | ряд пилюль: `01/04`, ‹ ›, чёрная CTA |
| Цвет | ноль | ноль | ноль |

Общее ДНК: **страница — это фотостудия, а не интерфейс.** Один объект на экран,
гигантское полупрозрачное слово за ним, крошечные подписи вразрядку, ряд
маленьких пилюль внизу, полное отсутствие цвета.

## 2. Мир: «Студийная витрина»

**Тезис.** Работы выставлены как товар в витрине дорогого магазина. Посетитель не
листает лендинг — он рассматривает предметы под студийным светом.

**Единственный цвет на всём сайте — его работы.** Вся страница нейтральна:
белая бумага, серая полка, чёрные буквы. Цвет появляется ровно один раз — внутри
экрана устройства, где стоит настоящий скриншот проекта. Это и есть позиция:
всё, кроме работы, выключено из цвета.

**Земля.** Полосы во всю ширину чередуются: белый лист → светлая студия → белый.
Никаких карточек с тенями, никакого стекла, никаких градиентов.

**Объект.** На каждом экране один предмет: устройство или скульптурная форма.
Парит, отбрасывает настоящую мягкую тень на землю. Все объекты — заранее
отрендеренные PNG, а не WebGL: выглядит объёмно, грузится как картинка.

**Слово-призрак.** За объектом — одно слово на 12–22vw, непрозрачность 5–8%.
На белом — почти чёрное; на серой полосе — белое (как в референсе 2).

**Управление.** Только пилюли: `rounded-full`, тонкая линия либо сплошной чёрный.
Подписи 10–11px, uppercase, трекинг 0.18em.

**Радиусы.** Пилюли — полные. Всё остальное — 0. Никаких «карточек 16px».

## 3. Подпись сайта — «Витрина»

Одна идея, проведённая насквозь, а не набор эффектов.

Герой — витрина. По центру стоит объект первого кейса, за ним призраком его
название, внизу ряд пилюль: `01 / 06`, ‹ ›, «Смотреть кейс». Перетаскивание
мышью, стрелки клавиатуры и свайп меняют предмет: уходящий приподнимается и
растворяется, тень пересобирается под новым, слово-призрак перекрёстно гаснет
полосами. Это переключатель товара из третьего референса, превращённый в
указатель работ.

Дальше метафора наследуется: услуги — предметы на полке, «обо мне» — портрет в
том же студийном свете, страница кейса — карточка товара.

Почему это уровень Awwwards: одна идея доведена до конца, взаимодействие
настоящее (мышь, клавиатура, тач), и оно быстрое, потому что за ним PNG и
CSS-трансформы, а не трёхмерная сцена.

## 4. Типографика

| Роль | Шрифт | Кириллица | Почему |
|---|---|---|---|
| Дисплей | **Prata** | да | Дидона с кириллицей, ближайшее попадание в логотип «the act» |
| Текст и интерфейс | **Onest** | да | уже лежит в `public/fonts`, нейтральный гротеск, хорош в мелком |

Запасной дисплей, если Prata не сядет: **Playfair Display** (кириллица есть).
Перед установкой проверить: `npm view @fontsource/prata version`.
Максимум два семейства и четыре файла.

Начертания: дисплей 400 (одно), Onest 400 и 500. Жирнее 500 не подниматься —
в этом мире вес заменяется размером и воздухом.

## 5. Палитра — токены

```css
--paper:  #FFFFFF;             /* белый лист */
--ground: #F1F0EE;             /* светлая студия, основной фон */
--shelf:  #E4E3E0;             /* серая полоса, «полка» */
--ink:    #0B0B0B;             /* текст */
--ink-2:  #6B6B68;             /* вторичный текст */
--ink-3:  #A3A29E;             /* подписи, счётчики */
--line:   rgba(11,11,11,.10);  /* волосяные линии */
--ghost:  rgba(11,11,11,.055); /* слово-призрак на светлом */
--ghost-invert: #FFFFFF;       /* слово-призрак на серой полке */
```

Акцентного цвета нет. Ни одного. Это решение, а не пробел.

## 6. Стек

Остаётся: **Next.js 15 App Router + React 19 + TypeScript + Tailwind + Prisma + Neon.**

Уходит:
- **Django на Railway.** Админка строится внутри Next.js — это записанное
  решение владельца («Backend stack = Next-native»). Одна кодовая база, один
  деплой. Railway-сервис не удалять до переезда, просто перестать зависеть.
- **Unbounded, lenis, gsap, framer-motion, split-type, все старые компоненты.**

Приходит:
- `motion` (motion.dev) — оркестрация витрины и переходов между страницами
- `@fontsource/prata`
- вход в админку: сессия на httpOnly-cookie + `bcrypt`, либо `next-auth`
- `zod` — валидация на границах
- `@vercel/blob` — остаётся, загрузка изображений кейсов

Трёхмерных библиотек нет. Объекты — PNG.

## 12. Твёрдые правила, которые переживают снос

- Репозиторий существующий: `.git` не удалять, remote не менять.
  `origin = https://github.com/alyoshagafurov/fullstack-developer.git`
- Секреты только в переменных окружения. `.env` и `.env.local` в git не попадают.

  прямого одобрения владельца, потому что `main` уходит в прод на Vercel.
