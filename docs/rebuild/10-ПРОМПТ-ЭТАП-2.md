## 7. ЧАСТЬ 4 — ВИТРИНА, подпись сайта

Компонент `components/vitrine/Vitrine.tsx`. Это главное, ради чего всё делается.

**Устройство.** По центру экрана объект текущего кейса, за ним слово-призрак, под
ним тень. Внизу ряд пилюль: счётчик `01 / 06`, стрелки ‹ ›, кнопка «Смотреть
кейс» на страницу этого кейса.

**Управление.** Перетаскивание указателем с примагничиванием к ближайшему,
стрелки ← → на клавиатуре, свайп на тач-экране, клик по ‹ ›. Все четыре способа
обязательны.

**Движение.** Только `transform` и `opacity`.

| Что | Как |
|---|---|
| уходящий объект | `translateY(-24px)` + `opacity 0`, 380 мс, ease-out |
| входящий объект | `translateY(24px) → 0`, `opacity 0 → 1`, 380 мс, задержка 60 мс |
| тень | масштаб и непрозрачность следуют за объектом |
| слово-призрак | перекрёстное затухание полосами через `clip-path`, 480 мс |
| счётчик | перекат цифры, 240 мс |

**Курсор.** На десктопе внутри витрины курсор заменяется маленькой подписью
«тянуть ↔». Выключается на тач-устройствах и при `prefers-reduced-motion`.

**Доступность.** Витрина — `role="region"` с `aria-roledescription="карусель"`, у
каждого объекта `aria-label` с названием кейса, живая область объявляет смену.
Стрелки ‹ › — настоящие `<button>` с подписями. Фокус виден.

**`prefers-reduced-motion`:** витрина превращается в статичный первый кейс,
переключение мгновенное, курсор обычный.

**Производительность.** Объекты через `next/image`, первый с `priority`,
остальные предзагружаются по одному вперёд и назад. Ни одного изображения тяжелее
180 KB после конвертации.
